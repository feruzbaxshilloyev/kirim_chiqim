# Kirim-Chiqim Hisoboti Loyihasi

Bu loyiha foydalanuvchining kundalik moliyaviy harajatlari va daromadlarini boshqarish uchun mo‘ljallangan. Foydalanuvchi o‘ziga tegishli valyutalarda kirim va chiqimlarni kiritadi hamda istalgan valyutani asos qilib tanlab, boshqa valyutalardagi miqdorlarni ushbu asosiy valyutaga konvertatsiya qilib umumiy hisobotni ko‘rishi mumkin.

## 🔧 Texnologiyalar
- Python 3.11+
- Django 5.2.1
- SQLite (yoki boshqa DBMS)
- HTML5, CSS3 (Bootstrap bilan)

## 📌 Asosiy funksiyalar
- Foydalanuvchi autentifikatsiyasi
- Kirim qo‘shish
- Chiqim qo‘shish
- Valyuta qo‘shish (faqat o‘z foydalanuvchisi uchun)
- Kirim/chiqimlarni valyuta va sanaga qarab filtrlash
- Asosiy valyutani tanlab, boshqa valyutalardagi kirim/chiqimlarni kurs asosida konvertatsiya qilish
- Hisobot sahifalari: umumiy balans, kirim va chiqim statistikasi
